# Лабораторные по Docker

Две лабораторные по мотивам вебинаров «Практика по Docker» (части 1 и 2)
плюс pro-уровень для тех, кто справился быстро.

## Как работать

1. Задания лежат в папках: `lab1/task01-...` … `lab1/task09-...` (по первому
   вебинару), `lab2/task01-...` … `lab2/task06-...` (по второму).
   Выполняйте **по порядку**.
2. В каждой папке — `README.md` с подробными шагами. Команды даны целиком;
   пропуски `____` и пометки **ВПИШИТЕ** заполняете сами.
3. `pro01`…`pro10` — задачи на самостоятельное развёртывание и настройку.
   Там готовых команд почти нет: есть цель, подсказки и критерий приёмки.
4. По каждому заданию в конце README написано, что сдать в отчёт.

## Если что-то не работает

- `Cannot connect to the Docker daemon` — запустите Docker Desktop
  (или `colima start`).
- `port is already allocated` — порт занят, поменяйте левую часть `-p`.
- Образ качается долго — это нормально, первый раз всегда долго.
- Полный сброс мусора после экспериментов:
  ```bash
  docker system prune -af --volumes
  ```
  Внимание: команда удаляет ВСЕ остановленные контейнеры, неиспользуемые
  образы и тома.
