# Pro 4. Бэкап и восстановление БД

**Цель:** настроить резервное копирование PostgreSQL из lab2 — и доказать,
что из бэкапа можно восстановиться.

## Задача

1. Напишите скрипт `backup.sh`: делает `pg_dump` базы `mydb` внутри
   контейнера и складывает файл с датой в имени в каталог `./backups`
   на хосте (подумайте, куда смонтировать каталог или как использовать
   `docker exec` + перенаправление).
2. Напишите `restore.sh`: восстанавливает базу из выбранного файла.
3. Проверка на честность: добавьте пользователя в таблицу, сделайте
   бэкап, удалите таблицу (`DROP TABLE users`), восстановите — данные
   вернулись.
4. Бонус: бэкап по расписанию через `cron` на хосте.

## Критерий приёмки

Скрипты + протокол проверки из пункта 3 (выводы команд до/после).
