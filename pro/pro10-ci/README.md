# Pro 10. Сборка образа в GitHub Actions

**Цель:** перенести сборку и публикацию образа в CI: на каждый push
в main образ собирается и уезжает в реестр.

## Задача

1. Выложите приложение из lab2/task04 в отдельный репозиторий на GitHub.
2. Напишите workflow `.github/workflows/docker.yml`:
   - триггер — push в main;
   - шаги: checkout → сборка образа → (бонус) прогон контейнера
     с проверкой, что он отвечает → push в Docker Hub
     (логин через секреты `DOCKERHUB_USERNAME` / `DOCKERHUB_TOKEN`;
     токен создаётся в настройках аккаунта Hub, НЕ пароль);
   - тег образа — не `latest`, а номер запуска или SHA коммита.
3. Докажите, что образ из CI реально работает: скачайте его на свою
   машину и поднимите стек через `image:` (как в lab2/task06).

## Критерий приёмки

Зелёный прогон workflow + `docker pull` свежего тега на локальной
машине + работающее приложение.
