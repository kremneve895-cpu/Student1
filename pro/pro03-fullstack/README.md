# Pro 3. Свой стек: web + db + cache

**Цель:** самостоятельно спроектировать и поднять трёхконтейнерный стек.

## Задача

Доработайте приложение из lab2 (или напишите новое на Flask):

1. Три сервиса в compose: `web`, `db` (PostgreSQL), `cache` (Redis).
2. Счётчик посещений главной страницы хранится в Redis (`INCR`),
   список пользователей — по-прежнему из PostgreSQL.
3. Пароли и параметры — в файле `.env`, в compose — через `env_file`
   или подстановку `${VAR}`.
4. У сервиса `db` настройте `healthcheck`, а `web` должен стартовать
   только после здоровой базы (`depends_on` с условием).
5. Снаружи доступен только `web`. База и кэш портов наружу не пробрасывают.

## Критерий приёмки

`docker compose up -d` → главная страница показывает список
пользователей и счётчик, который растёт при обновлении страницы.
`docker compose down && up` → счётчик сохранился (подумайте, что для
этого нужно).

## Что сдать

compose-файл, `.env.example` (без реальных паролей), скриншот страницы.
