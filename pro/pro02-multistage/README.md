# Pro 2. Многоэтапная сборка (multi-stage)

**Цель:** собрать образ, в котором нет инструментов сборки, — через
многоэтапный Dockerfile.

## Сценарий

Если приложение требует компиляции (в вебинаре для psycopg2 ставили
`build-essential` и `libpq-dev`), все эти компиляторы остаются в образе
навсегда — балласт и лишняя поверхность атаки.

## Задача

1. Напишите Dockerfile с двумя этапами: в первом (`AS builder`)
   ставятся зависимости и собирается всё нужное; во втором — только
   результат из первого (`COPY --from=builder`).
2. Проверьте на приложении из lab2/task04, заменив `psycopg2-binary`
   на обычный `psycopg2` (он компилируется — как раз повод для builder).
3. Сравните размер с одноэтапным вариантом.

## Критерий приёмки

Работающее приложение + вывод: почему в финальном образе не должно быть
компиляторов.
