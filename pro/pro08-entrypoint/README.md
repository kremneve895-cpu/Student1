# Pro 8. ENTRYPOINT vs CMD и сигналы

**Цель:** разобраться в разнице между ENTRYPOINT и CMD и научить
контейнер корректно завершаться.

## Задача

1. Соберите два варианта образа из одного скрипта `app.sh`
   (например, бесконечный цикл с печатью):
   - вариант A: `CMD ["./app.sh"]`;
   - вариант B: `ENTRYPOINT ["./app.sh"]`.
   Покажите, чем отличается поведение `docker run img argument`.
2. Проверьте `docker stop` на обоих вариантах: замерьте время остановки.
   Если контейнер «зависает» на 10 секунд — ваш процесс не ловит
   SIGTERM. Почините скрипт (`trap` или `exec`) так, чтобы остановка
   была мгновенной.
3. Объясните письменно: почему форма-список `["...", "..."]`
   предпочтительнее строковой формы с точки зрения сигналов
   (кто становится PID 1 в каждом случае)?

## Критерий приёмки

Таблица «вариант → поведение при docker run с аргументом → время
docker stop», рабочий trap/exec и вывод по пункту 3.
