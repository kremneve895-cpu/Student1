# Pro 7. Свой локальный registry

**Цель:** поднять собственный реестр образов и работать с ним вместо
Docker Hub — полный цикл push/pull без внешних аккаунтов.

## Задача

1. Поднимите `registry:2` контейнером (порт 5000, данные — в томе).
2. Перетегируйте образ `hello-docker` (или web из lab2) под адрес
   локального реестра и запушьте: `localhost:5000/...`.
3. Удалите локальные образы и скачайте заново — уже из своего registry.
4. Посмотрите каталог реестра через его API: `/_catalog` и список тегов.
5. Подумайте: как дать доступ к этому registry соседу по аудитории
   (что с сетью, что с HTTP/HTTPS)?

## Критерий приёмки

`docker pull localhost:5000/<ваш-образ>` работает после полного удаления
локальной копии; ответ API `/_catalog` содержит ваш образ.
