## Задание 4. Файлы проекта: Flask + PostgreSQL

### Ход работы

1. Заполнил app.py — имя хоста базы данных:
    host="db"
   В Compose сервисы видят друг друга по имени сервиса,
   поэтому приложение подключается к базе по имени db.

2. Заполнил docker-compose.yml (три пропуска):
   - порт приложения: "5001:5001" (см. app.run(host="0.0.0.0", port=5001) в app.py);
   - образ PostgreSQL: postgres:13 (по условию — версия 13);
   - пароль базы: mysecretpassword (совпадает с password в app.py).

3. Изучил init.sql:
    cat init.sql
   Содержимое:
    CREATE TABLE users (
        id SERIAL PRIMARY KEY,
        name VARCHAR(50)
    );
    INSERT INTO users (name) VALUES ('Alice'), ('Bob'), ('Charlie');

### Что будет в таблице users после первого запуска

Скрипт init.sql выполняется при первом старте базы (когда том pgdata пуст):
будет создана таблица users с двумя колонками (id — автозаполняемый
SERIAL, name — строка до 50 символов) и в неё добавятся три записи:

    id | name
    ---+---------
    1  | Alice
    2  | Bob
    3  | Charlie

Значения id проставятся автоматически: 1, 2, 3 — по порядку вставки.

### Вывод

Подготовлен стек из двух сервисов: web (Flask на порту 5001, собирается
из Dockerfile) и db (postgres:13 с паролем из app.py). При первом запуске
база автоматически инициализируется скриптом init.sql: таблица users
с тремя пользователями (Alice, Bob, Charlie). Приложение найдёт базу
по имени сервиса db. Запуск отложен до следующего задания.

Важно: init.sql выполняется только при пустом томе pgdata. При последующих
перезапусках данные сохраняются в томе, а скрипт не повторяется — чтобы
переинициализировать базу, нужно удалить том (docker compose down -v).
