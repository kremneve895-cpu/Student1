# Задание 4. Файлы проекта: Flask + PostgreSQL

**Что делаем:** готовим многоконтейнерное приложение — веб-сервис на Flask,
который читает список пользователей из PostgreSQL.

**Зачем:** приложения почти никогда не живут одним контейнером.
Здесь — связка «приложение + база», в следующем задании поднимем её
одной командой через Compose.

## Файлы в этой папке

- `app.py` — веб-приложение. ВПИШИТЕ пропуск: имя хоста базы данных
  (подсказка: в Compose сервисы видят друг друга по имени сервиса,
  как в задании 9 первой лабораторной);
- `requirements.txt` — зависимости Python;
- `init.sql` — скрипт, который PostgreSQL выполнит при первом запуске
  (создаст таблицу и наполнит её);
- `Dockerfile` — рецепт образа приложения (готовый);
- `docker-compose.yml` — описание стека. ВПИШИТЕ три пропуска:
  образ PostgreSQL (версия 13), порт приложения (смотрите `app.run`
  в `app.py`) и пароль базы.

## Шаг 1. Заполните пропуски

Откройте `app.py` и `docker-compose.yml`, впишите значения вместо `____`.

## Шаг 2. Изучите init.sql

```bash

```

Ответьте письменно: что будет в таблице `users` после первого запуска?
