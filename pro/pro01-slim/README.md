# Pro 1. Диета образа
**Цель:** уменьшить размер образа веб-приложения из lab2/task04 как минимум
в 2 раза и доказать это цифрами.

## Условия
- Приложение должно работать как раньше (стек поднимается, список
  пользователей отдаётся).
- Сравните `docker images` до и после.

## Что исследовать
- Чем отличаются базовые образы `python:3.8`, `python:3.8-slim`,
  `python:3.8-alpine` — соберите на каждом, сравните размеры;
- кэш pip (`--no-cache-dir`), число слоёв, `.dockerignore`;
- почему на alpine иногда всё ломается (подсказка: musl vs glibc).

## Критерий приёмки
Таблица «образ → размер» для минимум двух вариантов + работающее
приложение на самом маленьком. Письменный вывод: чем пожертвовали
ради размера.
