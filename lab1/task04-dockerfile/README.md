**Что делаем:** пишем Dockerfile для простого Python-приложения.

**Зачем:** Dockerfile — это рецепт сборки образа: из какого образа
начинаем, что копируем, какую команду запускаем.

## Шаг 1. Создайте приложение

В этой папке (`lab1/task04-dockerfile`) создайте файл `app.py`:

```python
print("Hello, Docker!")
```

## Шаг 2. Заполните Dockerfile

Откройте заготовку `Dockerfile` и ВПИШИТЕ два пропуска:

1. базовый образ — лёгкий вариант Python 3.8 (оканчивается на `-slim`);
2. команду запуска приложения.

## Шаг 3. Разберите каждую строку

Подпишите для себя (в отчёт), что делает каждая инструкция:
`FROM`, `WORKDIR`, `COPY`, `CMD`.
